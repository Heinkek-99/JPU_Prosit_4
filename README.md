# JPU_Prosit_4

Exercice de cours Java : jeu de conduite Insane Vehicles, écrit d'un seul tenant.

## Contenu

- `src/fr/exia/insanevehicles/` : classe principale, gestion du clavier, route et éléments mobiles
- `road.txt` : description de la carte, lue au démarrage
- `images/` : sprites du véhicule, des obstacles et du décor

## Stack

Java, Swing, lecture de fichiers pour la carte.

## Lancer le projet

Importer le projet dans Eclipse (fichiers `.project` et `.classpath` présents) et exécuter
`InsaneVehicles.java`.

## Contexte

Exercice d'école (2020), avant la découpe en modules Maven de `JPU_Prosit5`.
